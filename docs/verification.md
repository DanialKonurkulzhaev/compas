# Проверки Compas

Последний прогон: 28 октября 2026 года, локальный Windows + Docker Desktop.

## Автотесты

- Общий набор: 67 passed, 2 skipped. Инфраструктурные проверки запускаются отдельно.
- Проверяются расчёты всех 13 тестов, история прохождений, загрузка каталога, профиль, заявки, права доступа, алерты и вход через Яндекс.
- В `test_metriks.py` добавлены проверки пула соединений, отката транзакций, готовности БД, ограничений данных и авторизации.
- Тестовая БД — SQLite в памяти. PostgreSQL-массивы заменяются на JSON только в тестах.
- Покрытие до добавления `test_metriks.py`: 72% строк `src` при 54 тестах. После добавления новых тестов покрытие нужно измерить повторно.

## Docker и PostgreSQL

- Образы `app` и `migrate` собраны; миграции завершились с кодом 0.
- PostgreSQL 18 и API имеют статус healthy. `nginx -t` проходит.
- Swagger, OpenAPI, каталог тестов и изображения возвращают HTTP 200 через nginx на порту 8001.
- Применены миграции `compas_0001` и `compas_0002`; `alembic check` не выявил расхождений с моделями.
- После запуска контейнеров сохранились 1 пользователь, 13 тестов и версия схемы `compas_0002`.
- Проверены переход на Яндекс и cookie состояния. Живой вход через Яндекс и чтение `/auth/me` также прошли.

## Нагрузка и восстановление

Отдельно выполнены две инфраструктурные проверки: обе прошли.

GET `/tests`: 100 запросов, 10 одновременно, все HTTP 200. Получено 323,98 запроса/с, p50 9,85 мс, p95 162,73 мс. Это короткий локальный замер, а не предел производительности сервера.

Свежий PostgreSQL-дамп восстановлен в отдельную БД. Сравнены количества пользователей, прохождений и тестов, а также версия схемы. Прохождений в исходной БД не было, поэтому восстановление истории с зашифрованными результатами ещё не проверено.

Команды и условия запусков: [metrics.md](metrics.md).

## Ещё не проверено

- Нагрузка на запись, большой объём данных и сравнение 1/2/4 процессов API.
- Восстановление аватаров, расшифровка результатов после восстановления и время восстановления после сбоя хоста.
- Реальная отправка SMTP-писем, HTTPS и развёртывание на сервере.
- Полный аудит безопасности.
